# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful and constructive; no harassment, personal attacks, or gatekeeping;
assume good faith. Maintainers may edit or remove contributions that violate this and may
ban repeat offenders.

Report unacceptable behaviour to **white.dev.sc@gmail.com**. Reports are handled confidentially.
