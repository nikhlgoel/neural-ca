# data/

Datasets live here but are **never committed** — everything except this file is
gitignored, and a pre-commit hook blocks files over 1 MB as a second line of defence.

Rules:

1. Every dataset must be reproducible by a script in `scripts/` (download + checksum + preprocess).
2. Every dataset added gets a row in this table (source, license, version) — dataset licenses
   must permit our use and the redistribution of derived model weights (PRD NFR3).
