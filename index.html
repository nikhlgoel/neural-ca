02 / Where it helps

Built for curious builders.

This is a research foundation, not a drop-in product. Its value depends on whether your work benefits from tiny, local, inspectable rules.

ML / AI engineers

Learn the whole loop

Use it to practice architecture, training, evaluation, checkpointing, export, and reproducibility without hiding behind a large pretrained model.

Games / graphics

Explore living visuals

NCAs can inspire procedural growth, evolving textures, self-healing sprites, and worlds shaped by local interaction. This project is a starting point for those experiments.

Browser / edge

Ship less model

A 5.9 KB ONNX core points toward low-latency experiences that run on a laptop, phone, or browser without sending every interaction to a server.

Cloud / platform

Prototype efficiently

Useful for testing compact inference, artifact versioning, and reproducible experiment jobs. It is not a replacement for cloud-scale training or distributed systems.

Researchers / students

Study emergence

Change one factor at a time, run ablations, and inspect how local rules create global behavior. The docs make each decision and failure easy to follow.

Educators / writers

Explain models clearly

The model is small enough to map from equations to code, making it a useful teaching example for gradients, cellular systems, and iterative learning.

04 / Setbacks & risks

What can get in the way?

Stability is hard

NCA gradients can spike across many unrolled steps. Gradient normalisation and randomized firing keep the first runs from diverging.

Evidence is still pending

The early heart run is promising, but it is not yet a persistence or regeneration result. Those metrics are the next gate.

Scope stays deliberately tight

No frontier-model race, no production serving stack, no inflated claims. Build one reproducible result, document the setbacks, then extend it.
