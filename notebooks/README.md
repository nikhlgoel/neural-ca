# notebooks/

Exploratory work only. Ground rules:

1. Notebooks are scratch space — anything worth keeping graduates into `src/` (with tests)
   and its findings into `docs/devlog/`.
2. Clear all outputs before committing (keeps diffs reviewable and the repo small).
3. A notebook is never the source of truth for a reported result — results come from
   `scripts/` + `configs/` runs (see docs/DESIGN.md §8, reproducibility).
